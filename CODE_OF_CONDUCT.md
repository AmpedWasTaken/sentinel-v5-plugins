# Community code of conduct

We want Sentinel V5's plugin community to be welcoming, technically rigorous and respectful.

Contributors and maintainers should:
- Be constructive and assume good intent while discussing design, security and code.
- Discuss implementation choices rather than attacking people.
- Respect contributors' time and experience; offer actionable feedback.
- Avoid harassment, discrimination, threats, hate speech, sexualized abuse, doxxing and repeated disruption.
- Keep reports and review discussions focused on responsible use of technology.

Maintainers can edit, hide, close or reject contributions and restrict participation when behavior undermines community safety.

Report conduct concerns privately to a maintainer if possible; do not post personal details or sensitive reports in a public issue. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).

This policy covers issues, PRs, reviews, discussions and other project spaces. It is applied fairly while recognizing that strong technical criticism is not a personal attack.
